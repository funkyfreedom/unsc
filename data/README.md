# Data dictionary

Six CSV files, UTF-8, comma-separated, with a header row. Yes/no columns hold `yes` or `no`; an empty cell means the value isn't known. They're generated by `src/export.py` from the same dataset that builds the site, so every figure matches the pages.

## resolutions.csv

One row per adopted resolution, 1 to 2835 (January 1946 to October 2026).

| Column | Meaning |
|---|---|
| `resolution` | Resolution number |
| `symbol` | UN document symbol, e.g. `S/RES/678 (1990)` |
| `date`, `year` | Date of adoption |
| `era` | One of the site's eight eras (see eras.csv) |
| `subject` | The subject from the resolution's title |
| `region` | Region of the situation it concerns: Africa, Middle East, Europe, Asia, Americas, Institutional (admissions, elections, appointments), Thematic (general subjects) or Other |
| `countries` | Countries the resolution concerns, from CR-UNSC metadata, separated by `; `. Empty for resolutions after 2815 |
| `votes_yes`, `votes_no`, `abstentions`, `not_voting` | Vote counts |
| `unanimous` | `yes` if every member present voted yes |
| `acting_under_chapter_vii` | Text says the Council is acting, or taking action, under Chapter VII of the Charter |
| `threat_to_the_peace` | Text uses "threat to the peace" or "threat to international peace" |
| `breach_of_the_peace` | Council determines or states that a breach of the peace exists |
| `act_of_aggression` | Text uses "act(s) of aggression" or "act(s) of armed aggression" |
| `word_aggression` | Text uses "aggression" or "aggressive" |
| `word_decides` | Text uses "decides", the Council's binding verb |
| `all_necessary_means` | Text authorises "all necessary means" or "all necessary measures" |
| `themes` | Themes whose keywords appear in the text, separated by `; ` (see below) |
| `words` | Length of the text in words |
| `cites` | Earlier resolutions this one cites, space-separated. From the CR-UNSC citation network, so empty after 2815 |
| `cited_by` | How many later resolutions cite this one |
| `official_document` | Link to the official text |
| `page` | The resolution's page on securitycouncilrecord.org |

The Charter columns count phrases with patterns that allow for scanning errors. A `yes` means the phrase appears in the text, which isn't always a formal finding.

The 19 themes and what triggers them: Women, peace and security (women, gender); Children and armed conflict (children); Protection of civilians; Sexual violence; Terrorism; Sanctions and embargoes (sanctions, arms embargo, asset freeze, travel ban); Peacekeeping; Human rights; Humanitarian access and aid; Justice and impunity (impunity, accountability, international courts and tribunals); Elections; Weapons of mass destruction (also nuclear, chemical weapons); Health crises (HIV, Ebola, COVID, pandemic); Climate change; Piracy; Refugees and displacement; Ceasefires; Self-determination and decolonisation; Apartheid. The exact patterns are in `src/prep.py`.

## votes.csv

One row per member per recorded vote, January 1946 to December 2025. Covers adopted resolutions and drafts that were vetoed or failed.

| Column | Meaning |
|---|---|
| `date` | Date of the vote |
| `document` | Resolution symbol, or the draft or meeting symbol for drafts that weren't adopted |
| `outcome` | `adopted`, `vetoed` or `not enough votes` |
| `resolution` | Resolution number if adopted, otherwise empty |
| `country` | Member state as named in the Sciences Po database. "Russia / USSR" is one seat; China's seat was held by the Republic of China until October 1971 |
| `vote` | `yes`, `no`, `abstained`, `did not vote` or `unknown` |

Source: UNSC votes since 1946 database, Sciences Po. Resolution 2760 (2024) is missing from that file. Member-by-member votes for 2026 aren't in it yet; resolutions.csv has the 2026 vote counts from the UN's own files.

## drafts.csv

One row per draft that wasn't adopted: 270 vetoed and 123 that didn't get the nine votes needed.

| Column | Meaning |
|---|---|
| `date` | Date of the vote |
| `document` | Draft or meeting symbol |
| `subject` | Title of the item |
| `outcome` | `vetoed` or `not enough votes` |
| `votes_yes`, `votes_no`, `abstentions` | Vote counts |
| `vetoed_by` | Permanent members who voted no on a vetoed draft, separated by `; ` |

## citations.csv

One row per citation: `citing_resolution` mentions `cited_resolution` in its text. From the CR-UNSC citation network, resolutions 1 to 2815.

## eras.csv

One row per era, with the figures shown on the site's era pages.

| Column | Meaning |
|---|---|
| `era`, `from`, `to`, `opened_by` | Name, years and the event that opened it |
| `resolutions`, `per_year` | Resolutions adopted, in total and per year |
| `unanimous_pct` | Share adopted unanimously |
| `vetoed_drafts`, `failed_drafts` | Drafts vetoed, and drafts that didn't get enough votes |
| `chapter_vii_pct`, `threat_to_the_peace_pct`, `word_aggression_pct`, `word_decides_pct` | Share of resolutions using each term |
| `median_words` | Median length of a resolution |
| `vetoes_russia_ussr` … `vetoes_china` | Vetoed drafts each permanent member voted against |

## countries.csv

One row per country that has sat on the Council.

| Column | Meaning |
|---|---|
| `country` | Name |
| `permanent_member` | `yes` for the five permanent members |
| `years_with_votes`, `first_year`, `last_year` | Years in which it voted |
| `yes_on_adopted`, `abstentions_on_adopted`, `no_on_adopted` | Its votes on resolutions that were adopted |
| `no_on_failed_or_vetoed` | Its no votes on drafts that were vetoed or failed |
| `page` | Its page on securitycouncilrecord.org |
